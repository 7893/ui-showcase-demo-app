# Contributing

## Requirements

- Node.js >= 24
- npm >= 10

## Getting Started

```bash
git clone https://github.com/7893/ui-showcase-demo-app.git
cd ui-showcase-demo-app
npm install --legacy-peer-deps
npm run dev
```

## Guidelines

- Commit messages must be in English, max 8 words
- Run `npm run lint` and `npm run build` before submitting a PR
- All PRs target the `main` branch
